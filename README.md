One micro-confession in exactly two parts: a `To:` line naming who it was
meant for, and the unsent message itself, one line written exactly as it
was typed, with no explanation after it.

## The entry

```text
To: Dad
I practiced saying sorry in the car for three years and by the time I could say it without crying you were already gone.
```

## Run it

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Pure Python standard library — no network, no secrets, no input.
